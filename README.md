# 閱讀小將｜STAR／ORID 學習單助手

為新北市立板橋國民中學八年級閱讀活動製作的純前端示例網站，部署到 GitHub Pages 後即可使用，不需要 API Key、伺服器或資料庫。

## 使用流程

1. 輸入五位學生代號，例如 `81501`、`81617`。
2. 只顯示該班兩本指定書籍，點選書籍後自動帶入 STAR 或 ORID 學習單。
3. 依序閱讀四個階段的原則與提問，點擊「顯示本題回答」查看參考示例。
4. 可以複製單題回答、返回上一題、切換書籍或重新開始。

## 文字產生規則

- 四書各自有獨立、依書籍內容撰寫的題目及答案片語。
- 每個階段使用三種理解層次、四種具體觀察、四種補充反思及七種句首。
- 依座號固定組合，**相同班級／座號／書籍／題目**的參考文字保持一致，方便老師覆核。
- 對同一本書同一題，座號 01–99 的 99 種組合都不會完全重複。
- 驗證範圍：4 本書 × 4 題 × 99 個座號，共 1,584 個回答；截至建立時均為 **30–50 字**（不計標點及空白）。
- 回答內容屬於閱讀示例，不是原書逐字摘錄或唯一標準答案。書籍章節、版次、頁碼需要依實際持有的紙本核對。系統不會捏造頁碼。
- 姓名不需要輸入；學生代號只在使用者自己的瀏覽器運作，不會主動傳送或留存。

## 檔案

- `index.html`：頁面、樣式、使用流程。
- `data.js`：四本書內容、四階段題目、三個層次的答案素材與來源網址。
- `app.js`：班級判斷、答案組合、字數驗證、逐題切換與複製。

## 啟用 GitHub Pages

在 GitHub 儲存庫中打開 **Settings → Pages → Build and deployment**，選擇 **Deploy from a branch**，分支選 `main`、資料夾選 `/(root)`，儲存後即可用此網址開啟：

https://kaoelvmpvm.github.io/huidu-bot/

如果此專案尚未啟用 Pages，上述網站暫時無法開啟，請先完成設定。
